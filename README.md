# 80s Arcade Games

A collection of 8-bit style arcade games built with HTML5 Canvas and Vanilla JS. Made with love for animal-loving kids.

## Games

| Game | Description | Play |
|------|-------------|------|
| [Hoppy's Crossing](./hoppy-crossing/) | Frogger-style bunny crossing adventure | Open `hoppy-crossing/index.html` |
| [Giraffe Munch](./giraffe-munch/) | Pac-Man style giraffe leaf-eating game | Open `giraffe-munch/index.html` |

## Running a Game

No build step required. Just open the game's `index.html` in a browser:

```bash
open hoppy-crossing/index.html
```

Or serve locally:

```bash
npx serve .
# then visit http://localhost:3000/hoppy-crossing/
```

## Controls

| Key | Action |
|-----|--------|
| Arrow keys / WASD | Move |
